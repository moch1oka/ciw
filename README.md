# Vân Trùng (云虫 / Cloud Insect) - Trọn bộ các Chapter

Tác giả: **WLOP** | Website gốc: [cloudinsect.com](https://cloudinsect.com/)

Toàn bộ truyện đã được tải về và sắp xếp ngăn nắp theo từng thư mục chapter độc lập, gồm đầy đủ **hình ảnh, hoạt cảnh video chuyển động, văn bản 11 ngôn ngữ (bao gồm bản dịch Tiếng Việt chất lượng cao) và trình đọc Offline trên trình duyệt**.

---

## 🇻🇳 Bản Dịch Tiếng Việt (Vietnamese Translation)
Đã hoàn thành chuyển ngữ toàn bộ **10 chapters** (hơn 700 đoạn hội thoại và văn cảnh) sang tiếng Việt:
- **Chuẩn hóa danh xưng & thuật ngữ Hán - Việt**: 
  - *Hi Dương* (Suvan / 希扬), *Nguyệt Nha Nhi* (Mahina / 月牙儿), *Vân Trùng* (Cloud Insect / 云虫)
  - *Nón ánh sáng* (Light Cone / 光锥), *Ngoài nón ánh sáng* (Beyond Light Cone / 光锥之外)
  - *Công Tôn Ưởng / Thương Ưởng* (Gongsun Yang / Shang Yang / 公孙鞅 / 商鞅), *Trương Lương / Tử Phòng* (Zhang Liang / Zifang / 张良 / 子房)
  - *Tây Sở Bá Vương Hạng Vũ* (Xiang Yu / 项羽), *Chiến mã Ô Chuy* (Wuzhui / 乌骓), *Bến Ô Giang* (Wujiang / 乌江)
  - Trích dẫn chính xác các đoạn trích sử liệu từ 《Sử ký · Thương Quân liệt truyện》, 《Sử ký · Lưu Hầu thế gia》 của Tư Mã Thiên, danh ngôn Trương Ái Linh, Oscar Wilde.
- **Trình đọc HTML Offline tích hợp sẵn Tiếng Việt**: Bạn chỉ cần chọn mục **Tiếng Việt** trên thanh ngôn ngữ ở góc trên màn hình.

---

## 🚀 Các cách đọc truyện:
1. **Đọc trên trình duyệt (Khuyên dùng):** Mở file [`index.html`](./index.html) tại thư mục gốc để vào trang chủ, hoặc mở file `index.html` trong từng thư mục chapter. Chuyển sang `Tiếng Việt` để thưởng thức trọn vẹn bản dịch cùng hiệu ứng chuyển cảnh và video motion comic.
2. **Đọc dạng Markdown thuần Tiếng Việt:** Xem file `chapter_vi.md` trong từng chapter.
3. **Đọc dạng Markdown Đối chiếu (VI - ZH - EN):** Xem file `chapter_vi_bilingual.md` trong từng chapter.
