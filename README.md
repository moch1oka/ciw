## Bản Dịch Tiếng Việt (Vietnamese Translation)
Đã hoàn thành chuyển ngữ toàn bộ **11 chapters** (hơn 800 đoạn thoại và văn cảnh) sang tiếng Việt:
- **Chuẩn hóa danh xưng & thuật ngữ Hán - Việt**: 
  - *Hi Dương* (希扬), *Nguyệt Nha Nhi* (月牙儿), *Vân Trùng* (云虫), *Người Trong Mây* (云中人)
  - *Nón ánh sáng* (光锥), *Ngoài nón ánh sáng* (光锥之外), *Nón định mệnh* (命运之锥)
  - *Thông tin có trật tự* (有序信息), *Thông tin vô trật tự* (无序信息)
  - *Công Tôn Ưởng / Thương Ưởng* (公孙鞅 / 商鞅), *Trương Lương / Tử Phòng* (张良 / 子房)
  - *Tây Sở Bá Vương Hạng Vũ* (西楚霸王项羽), *Chiến mã Ô Chuy* (乌骓), *Bến Ô Giang* (乌江), *Đình trưởng Ô Giang*
  - *Hán Quang Vũ Đế Lưu Tú* (汉光武帝刘秀), *Bá Lăng* (霸陵)
  - Trích dẫn chuẩn xác các đoạn trích sử liệu từ 《Sử ký · Thương Quân liệt truyện》, 《Sử ký · Lưu Hầu thế gia》, 《Sử ký · Hạng Vũ bản kỷ》 của Tư Mã Thiên, danh ngôn Trương Ái Linh, Oscar Wilde.
- **Trình đọc HTML Offline tinh gọn**: Đã loại bỏ hoàn toàn các ngôn ngữ thừa, chỉ giữ lại **Tiếng Việt** và **Tiếng Trung Giản Thể (简体中文)**. Mặc định khởi chạy ngay bằng Tiếng Việt với phông chữ tiếng Việt chuẩn đẹp **Be Vietnam Pro**. Tự động ghi nhớ lựa chọn bằng `localStorage` cho tất cả các chương.

## Các cách đọc truyện:
1. **Đọc trên trình duyệt (Khuyên dùng):** Mở file [`index.html`](./index.html) tại thư mục gốc để vào trang chủ, hoặc mở file `index.html` trong từng thư mục chapter. Bạn có thể dễ dàng chuyển đổi qua lại giữa `Tiếng Việt` và `简体中文` trên thanh điều hướng.
2. **Đọc dạng Markdown thuần Tiếng Việt:** Xem file `chapter_vi.md` trong từng chapter (chuẩn văn phong, dịch chữ trong ảnh và thoại).
3. **Đọc dạng Markdown Đối chiếu (VI - ZH):** Xem file `chapter_vi_bilingual.md` trong từng chapter (đối chiếu trực tiếp từng câu Tiếng Việt và Tiếng Trung giản thể).
